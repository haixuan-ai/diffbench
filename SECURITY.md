# Security and integrity reports

* Scorer/verification bugs (a way to make a result look better or worse than it is, to forge a bundle, or to leak hidden-set variants before reveal) are treated as security issues. Report privately to **haiping-liang@qq.com** (or via GitHub private vulnerability reporting). Please do not open a public issue until fixed. Target: acknowledge in 3 working days, fix or publish a mitigation in 30 days.
* Hosted API abuse (rate-limit bypass, DoS) – same channel.
* Credit is given in `CHANGELOG.md` unless you ask otherwise.
