# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, argue about evidence not people, and assume good faith from engine maintainers whose results are being published. Report conduct issues to **haiping-liang@qq.com**. Maintainers may remove comments, issues or contributions that violate these norms.
